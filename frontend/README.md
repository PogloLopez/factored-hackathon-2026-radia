# frontend/

**Dueño: Esteban (Fullstack Dev).**

Web de demostración. Login, vista de cuenta con carrusel de preaprobados, chat, bandeja del analista y consola del asesor.

## Cómo arrancar sin backend real

1. Levantar el stub que sube Edwin (ver `src/radia/backend/README.md`).
2. Abrir `/docs` del stub para ver qué manda y qué recibe cada endpoint.
3. Construir las pantallas contra el stub. Cuando Edwin conecte la lógica real, la forma de las respuestas no cambia.

- `package.json` y su lockfile son de Esteban.
